DECIDED (executed)

[x] App is Vaultly (Python/FastAPI, KV v2)

[x] Vault storage is Raft
    Running on kind (1 replica, local dev).

[x] Local practice is kind (1 CP + 2 workers)

    Version-controlled, in use.

    ServiceAccount vaultly-sa, bound to Vault role "vaultly".
    Static root token removed from app. Root token retained for admin ops only.
    Same flow applies on EKS (no changes needed when migrating).

[x] K8s auth method enabled and verified
    vault auth enable kubernetes + config (kubernetes_host in-cluster).
    Policy vaultly-policy (secret/data/vaultly/*, secret/metadata/vaultly/*).
    Role vaultly (bound SA: vaultly-sa, bound ns: vaultly, ttl=1h, max_ttl=4h).
    ClusterRoleBinding vault-tokenreview-binding (vault:vault → system:auth-delegator).
